## 0. 本書の使い方

本書は `/clear` 後でも本書だけで反映作業が完結するように書かれている。反映者は「2. 変更（D1〜D2）」を順に適用する。「3. 反映後の検証」「4. 完了処理」は Claude Code 本体が行う。各変更は「位置」「変更前（全文）」「変更後（全文）」で示す。位置の指定は見出しと前後の文で行い、行番号は参考（基準コミット時点の値）。変更前のテキストは現行ファイルに一意に存在する（反映前に一致を確認すること）。

## 1. 方針

- **実施者**: D1・D2（`template/CLAUDE.md`）はルート `CLAUDE.md` ステップ5 の規定どおり Sonnet サブエージェントに委任する
- **テスト**: コード変更がないため不要
- **変更対象ファイル**: `template/CLAUDE.md`（D1・D2）、（完了処理で）本案件 `README.md`
- **変更しないファイル**: ルート `CLAUDE.md`・ルート `AGENTS.md`、`template/AGENTS.md`、`template/docs/` 配下全部、`template/.gitignore`、他案件の文書
- **変更方式**: 行内置換のみ（D1・D2 は各1行）。各項に変更前・変更後の全文を記載
